# 优先关注的新闻类型

* Nature、Science、Cell 及其重要子刊发表的水稻或植物育种研究
* 新发现的重要基因、QTL、单倍型、结构变异或调控元件
* 新发布的水稻基因组、泛基因组、种质资源或大规模表型数据
* 新开源的育种模型、DNA 基础模型、生物信息学工具和数据平台
* 能显著提升育种效率、预测准确率或候选基因定位能力的方法
* 已完成田间验证、品种审定或产业化应用的重要成果
* 对水稻育种具有明确借鉴价值的其他作物研究
* 具有长期研究价值或可能形成持续研究方向的技术进展

# 低优先级或跳过的内容

* 仅描述常规品种展示、会议召开或领导调研，缺少实质科研信息
* 仅有宏观宣传，没有明确基因、技术、数据、方法或育种结果
* 与农业关系较弱，仅在标题中泛泛使用“AI”“智慧农业”等词语
* 仅为企业宣传、产品广告、培训招生或付费课程推广
* 重复报道已经广泛传播、没有新增信息的研究成果
* 仅基于细胞、温室或苗期实验，且没有说明田间或育种应用价值
* 结论过度外推，样本量过小或缺少独立验证的研究
* 仅关注其他作物，且方法和结果无法迁移至水稻育种

# 标题质量要求

# 即使匹配了上面的标签，符合以下特征的标题也请跳过

* 不要标题党或震惊体，如“震惊”“重磅突发”“刚刚”“竟然”“颠覆”
* 不要营销软文、企业广告、课程推广或付费社群内容
* 不要只有口号，没有具体研究对象、方法或结果的标题
* 不要夸大“世界首个”“彻底解决”“全面超越”等未经证实的结论
* 不要将普通相关性研究包装为因果机制或重大育种突破
* 不要重复转载同一新闻，优先保留论文原文、机构官网或权威媒体来源

3. 数据库、软件项目主页、GitHub 和正式技术文档

# 分类原则

* 优先依据新闻的核心科学问题分类，而不是仅依据标题关键词。
* 同一成果涉及多个方向时，只归入优先级最高的主要方向。
* 水稻研究优先于其他作物研究，野生稻和育种应用优先于纯基础描述。
* 同时涉及方法创新和具体性状时，优先归入与水稻育种应用最直接的方向。
* 对尚未进行田间验证的研究，应标记为“机制研究”或“早期方法研究”。
* 对已经进入品种培育、审定或产业化阶段的成果，应标记为“育种应用”。
* 对包含可复用数据、代码或模型的研究，应优先保留并标记“资源开放”。
