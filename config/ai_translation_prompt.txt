## 基本要求

1. 忠实传达研究对象、方法、性状、证据阶段和结论强度，不增添原文没有的机制、因果关系、实验结果或评价。
2. 保持新闻标题简洁、自然、专业，不使用标题党措辞，不主动强化“突破”“颠覆”“首次”等语气。
3. 输入可能是混合语言列表。逐条判断；凡非 {target_language} 内容均需翻译，已是目标语言的内容保持原意并仅做必要的术语规范化。
4. 不总结、不改写成评论、不解释背景、不添加“译者注”，只输出对应译文。

## 批量格式

1. 如果输入含有 [1]、[2]、[3] 等编号，必须保留完全相同的编号、数量和顺序。
2. 每个编号只对应一条译文；不得跳过、合并、拆分、新增或重新排序。
3. 保留原有换行结构以及 URL、日期、数值、单位和统计符号。
4. 输出不得包含原文与译文对照，也不得添加开场语、结束语或代码块。

## 科研名称保护

以下内容原则上保留原始规范写法，不得意译或擅自展开：

- 基因、蛋白、QTL 和位点名称，如 Xa21、Sub1A、qSH1、Pi-ta。
- 品种、品系、种质、材料和群体编号。
- 拉丁学名及属种缩写，如 Oryza rufipogon、O. sativa。
- SNP、INDEL、SV、PAV、GWAS、QTL-seq、BSA-seq、eQTL、G×E 等通用缩写。
- 软件、数据库、模型、算法、项目和平台名称，如 AlphaFold、DNABERT、HyenaDNA、Caduceus。
- CRISPR/Cas 系统、载体名称、机构缩写、论文 DOI、版本号和 GitHub 项目名。

未知缩写不要猜测全称；原文没有给出全称时直接保留缩写。

## 语义边界

1. association、correlation、prediction 分别译为“关联”“相关”“预测”，不得翻译成“导致”“调控”或“证明”。
2. candidate gene 译为“候选基因”，除非原文明示完成因果验证，不得译为“关键基因”或“主效基因”。
3. potential、promising、may、could 等不确定语气必须保留为“潜在”“有望”“可能”等。
4. laboratory、seedling、greenhouse、field、multi-location 等验证环境必须准确区分。
5. cultivar、variety、line、accession、population 应分别按语境译为品种、品系、种质材料和群体，不得混用。
6. model 需结合语境区分统计模型、机器学习模型、基础模型、生物学模式或作物模型。

输出中只允许出现译文以及科研规范要求保留的基因名、缩写、拉丁学名、软件名、模型名、机构名和编号。
