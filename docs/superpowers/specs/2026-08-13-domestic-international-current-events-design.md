# 时事动态研判按国内与国外拆分设计

## 目标

周报仍使用现有 `current_events_trends` JSON 字段，但字段正文必须固定分为“国内动态”和“国外动态”两部分，使 PDF 中的时事研判地域结构清晰，同时不改变现有解析、严格校验和 PDF 渲染接口。

## 输出格式

`current_events_trends` 必须按以下顺序输出：

1. `【国内动态】`：概括中国大陆中央与地方政府、国内科研机构、企业和产业动态。
2. `【国外动态】`：概括其他国家、境外机构及国际组织发布的动态。

国际组织按发布主体归入国外动态，即使其内容涉及中国项目。每部分只能引用实际支持该部分结论的 `[current_events:N]` 证据。同一新闻不得在两部分重复使用。

若某部分没有可用新闻，必须在该部分明确写“本期暂无相关动态”，不得引用另一部分新闻补齐，不得根据常识虚构内容。

## 改动范围

- 修改 `config/ai_analysis_prompt.txt` 中 `current_events_trends` 的生成要求与 JSON 示例。
- 增加静态 Prompt 契约测试，固定两个标签、归类规则、空态规则和禁止重复规则。
- 不新增 JSON 字段。
- 不修改 AI 响应解析、证据 ID 校验、PDF 模板、科研研判或农业气象研判。

## 验收标准

- 周报 Prompt 明确要求依次输出 `【国内动态】`、`【国外动态】`。
- 国内、国外及国际组织的归类边界明确。
- Prompt 明确要求两部分分别引用真实时事证据，且同一新闻不得重复。
- 任一部分无内容时使用规定空态，不跨区补齐。
- 现有周报分析与配置测试继续通过。
