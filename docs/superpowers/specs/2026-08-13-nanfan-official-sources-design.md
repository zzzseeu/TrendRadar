# 南繁官方固定监控源设计

## 目标

将以下三个官方栏目加入固定新闻源，使每次采集都会主动访问，而不只依赖 Google News 在线搜索：

1. 海南省农业农村厅“中国南繁·新闻简讯”
2. 三亚市农业农村局“部门文件”
3. 三亚市农业农村局“工作动态”

## 固定入口

- `https://agri.hainan.gov.cn/hnsnyt/zgnf/xwzx/xwjx/`
- `https://ny.sanya.gov.cn/nyjsite/bmwjxx/newxxgklist.shtml`
- `https://ny.sanya.gov.cn/nyjsite/gzdt/list2.shtml`

“中国南繁”的导航入口会通过 HTML meta 跳转到子栏目；配置直接使用最终列表页，避免抓取器无法跟随 meta 跳转。

## 接入方式

三个来源继续复用现有 `web_news` 抓取和解析链，不新增第二套爬虫：

- 在中英文配置的 `rss.feeds` 中加入三个启用的固定源。
- 在 `_PROFILES` 中登记各自的作者、文章 URL 规则和日期要求。
- 列表页缺少可解析条目时维持现有 fail-closed 行为，记录来源失败，不伪装成成功空抓取。

## 内容范围

“中国南繁·新闻简讯”是南繁专栏，保留列表中的全部带日期条目，包括由该官方专栏链接到其他权威媒体或政务平台的条目。

三亚市农业农村局的两个栏目属于综合农业栏目，只保留标题或列表摘要明确包含以下任一词语的候选：

`水稻`、`稻米`、`稻谷`、`稻作`、`南繁`、`种业`、`育种`、`制种`、`种质`、`品种`

该预过滤只降低明显无关的渔业、畜牧和一般政务噪声；候选仍须经过现有自然周发布时间窗口、AI 相关性阈值、物种规则、去重和模块分类。

## 数据与展示

- 来源类别为官方时事来源，不标记为学术期刊。
- 作者分别显示为“海南省农业农村厅中国南繁”和“三亚市农业农村局”。
- 文章 URL 保留最终官方或专栏选定的原始链接。
- 不改变现有搜索主题、AI 阈值、Top 20、PDF 结构和企业微信投递逻辑。

## 验证

使用离线、贴近真实页面结构的 HTML 片段验证：

- 三个 profile 都能提取标题、发布日期、URL 和作者。
- 中国南繁允许专栏中带日期的外部权威链接。
- 三亚两个综合栏目排除不含水稻、南繁或种业关键词的条目。
- 中英文配置包含相同的三个启用源和精确入口。
- 现有官方来源解析测试保持通过。
