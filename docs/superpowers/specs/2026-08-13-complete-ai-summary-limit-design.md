# AI 新闻摘要完整句与 450 字上限设计

## 目标

修复周报新闻卡片摘要在固定字符位置被截成残句的问题。每条 AI 摘要最多 450 个字符，并以完整句子结束；数据库、HTML 和 PDF 中不得出现由程序截断产生的半句话。

## 规则

- 分类 Prompt 明确要求：有正文或摘要证据时，生成不超过 450 字的中文摘要，并以完整句子结束。
- 程序删除所有针对 `ai_summary` 的固定字符切片，不再用 `[:300]` 或 `[:450]` 修改模型内容。
- 解析模型结果时只做规范化和校验：摘要必须非空、长度不超过 450，并以句末标点结束。
- 句末标点接受中文或英文的句号、问号、感叹号；闭合引号或括号可以位于句末标点之后。
- 只有标题证据时生成的简短摘要也遵循相同的完整句规则。
- 摘要超长或不是完整句时，视为无效 AI 响应，沿用现有 JSON 修复/批次重试流程；不得静默截断后保存。

## 数据流

AI 分类响应 → 摘要规范化与完整性校验 → 摘要证据校审 → 再次执行相同校验 → SQLite 保存 → PDF 原样渲染。

PDF 渲染层不设置摘要字数限制，也不承担修复职责。

## 验证

- 300–450 字且完整结束的摘要可保存并完整渲染。
- 超过 450 字的摘要触发无效响应，不被裁剪保存。
- 450 字以内但以残词或残句结束的摘要触发无效响应。
- 校审返回的超长或残句摘要同样被拒绝。
- 现有短摘要、仅标题摘要和普通/严格分类模式保持可用。
