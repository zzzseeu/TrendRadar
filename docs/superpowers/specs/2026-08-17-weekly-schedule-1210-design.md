# 周报定时调整设计

## 目标

将每周一周报的自动触发时间统一为北京时间 `12:10`、`12:30`、`13:00`、`13:30`；周二至周日仍在 `10:00` 静默采集。

## 设计

- Docker 默认 Cron、`docker/.env` 与 `docker/.env.example` 使用同一组表达式：`0 10 * * 2-7;10,30 12 * * 1;0,30 13 * * 1`。
- 周一不再执行每日 `10:00` 触发；仅执行四次周报触发。
- 中英文时间线中的 `monday_weekly` 有效窗口同步改为 `[12:10, 13:31)`，确保四次触发均进入周报模式，其他时刻不会误运行周报。
- `config/daily.crontab` 与项目交接文档、README、技术说明同步更新，避免部署入口之间再次产生时间差异。
- 不改变上一自然周的内容范围、静默采集逻辑、幂等检查点或 PDF 投递逻辑。

## 验证

- 配置测试精确断言中英文周一窗口及四个触发时刻。
- 可移植部署测试精确断言默认 Cron、示例环境变量和 crontab 活动项。
- 运行相关 Python 配置测试、Shell 部署测试和 `git diff --check`。
